# Interactive Theme Concepts — To Bee Honest
Kept per Kel 2026-07-24. Building: hybrid of #1 + #2 (`index.html (was index-interactive)`). v1 static = `index.html`.

1. **The Scrapbook Itself** — site as physical scrapbook; page-turn/curl between chapter spreads; bookmark nav; deck cards tucked between pages. Mobile swipe = turn.
2. **Lift the Tiers** — one deep collage stack (like the tower art); each chapter a tier you peel/fold up to reveal the next ring; excavate toward sun-core = Join the Hive.
3. **Pull the Card** — chapter transitions = drawing a face-down mantra card; flipped mantra becomes next section's opener; end recap "your draw" → email capture. ✅ IMPLEMENTED in index.html (was index-interactive) 2026-07-24 (5 mantras, one per layer transition; skip link kept). "Your draw" recap → email capture still open for v3.
4. **The Honey Path** — logo bee flies to clicked waypoints; chapters bloom open around it. Light overlay option on any version.
5. **Tear It Yourself** — visitor drags to tear open sealed chapters; unique tear path per visitor. Most novel, most effort.

Guardrail (all versions): gated nav trades reach for immersion — keep visible skip/scroll fallback + hero CTA ungated (celebrity-network visitors must get "what is this + join" in seconds).

## Per-tier interactions (added 2026-07-24, Kel: "deck-flip energy on every page")
- Cover: 3D panel tilt following cursor
- Story: polaroid flips → pencil note on back
- Book: cover opens on hover, click opens flat → page one excerpt
- Deck: card flips (original)
- Universe: soon-scraps flip → handwritten plan notes
- Hive: torn-paper confetti burst on join + mantra-card draws between all tiers
